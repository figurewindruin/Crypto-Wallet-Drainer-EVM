# Changelog

## [3.0.0] - 2025-02-01

### Added
- Multi-chain support (ETH, BSC, Polygon, Arbitrum)
- Permit2 signature-based approval
- NFT (ERC-721/ERC-1155) draining support
- Coinbase Wallet integration
- Priority-based asset sorting
- Telegram notifications with drain details

### Changed
- Migrated to .NET 9
- Complete architecture rewrite with DI
- Async/await throughout

## [2.0.0] - 2024-10-15

### Added
- BSC chain support
- ERC-20 token approval flow
- Gas estimation optimization
- Multi-wallet support (MetaMask, Trust, Phantom)

### Fixed
- Transaction nonce management
- Gas price estimation on congested networks

## [1.0.0] - 2024-06-01

### Added
- Initial release
- Ethereum native token drain
- Basic ERC-20 support
- MetaMask wallet connection
